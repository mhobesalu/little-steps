# Little Steps

Visual routine app for kids: picture cards for morning, going out and bedtime, one step at a time with "Next up" and a gentle timer bar. English + Estonian (add a language by copying the `en` block in `STR` and `CARDS`).

- One-time purchase, no ads, no accounts. All data stays on the device (localStorage).
- All picture cards are original inline SVG drawings.
- Grown-up area: hold the gear button for 1.2 s.

Prototype stage: single `index.html`. Plan: wrap with Capacitor (bundle ID `ee.silgrowth.littlesteps`), seller Sild Growth OÜ.
